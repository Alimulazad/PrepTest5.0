# JACHAI (যাচাই) — Database Data Injection & Admin CMS Manual

**Document Version:** 2.0 (Production Architecture)  
**Target Audience:** Admins, Content Creators, OCR Engineers, Database Administrators

---

## ভূমিকা (Overview)
এই ফাইলে JACHAI প্ল্যাটফর্মের ডেটাবেজে সঠিকভাবে **Subject**, **Chapter**, **Topic**, **Question**, **Drafts** এবং **Knowledge Snippet** যুক্ত ও রক্ষণাবেক্ষণ করার পূর্ণাঙ্গ নিয়মাবলী, SQL স্ক্রিপ্ট, JSON স্কিমা এবং Admin CMS ওয়ার্কফ্লো বিশদভাবে লিপিবদ্ধ করা হলো।

## ৩. Admin CMS Workflow & Drafts Management

JACHAI প্ল্যাটফর্মে ডেটা যুক্ত করার ২টি প্রধান উপায় রয়েছে:

### ১. Admin Web Panel (`/admin`)
- **Login:** `/admin` রুটে যান এবং সুরক্ষিত অ্যাডমিন পাসওয়ার্ড প্রদান করে JWT টোকেন গ্রহণ করুন।
- **Question Management:** অ্যাডমিন প্যানেলের "প্রশ্ন তৈরি করুন" বাটনে ক্লিক করে নতুন প্রশ্ন ড্রাফট বা সরাসরি পাবলিশ করা যায়।
- **Topic Linkage:** প্রতিটি প্রশ্নের জন্য সাবজেক্ট ও চ্যাপ্টার সিলেক্ট করলে সংশ্লিষ্ট টপিকগুলোর ড্রপডাউন স্বয়ংক্রিয়ভাবে লোড হয়।
- **Bulk Import (JSON Batch):** একসঙ্গে একাধিক প্রশ্ন ইমপোর্ট করতে JSON অ্যারে পেস্ট করে "Batch Upload" করা যায়।

### ২. Drafts Review & Approval Queue (`/api/admin/drafts`)
- এআই এক্সট্রাকশন বা বাইরের অপারেটরদের ইনপুট সরাসরি মূল প্রশ্ন ব্যাংকে যায় না; এগুলো `admin_drafts` টেবিলে `status = 'pending'` হিসেবে জমা হয়।
- অ্যাডমিন প্যানেলের "Drafts Queue" ট্যাবে পেন্ডিং প্রশ্নগুলোর প্রিভিউ, ম্যাথ ল্যাটেক্স এবং সঠিক উত্তর দেখা যায়।
- **Approve:** প্রশ্নটি যাচাই করে `POST /api/admin/drafts/:id/review` (`{ "action": "approve" }`) পাঠালে স্বয়ংক্রিয়ভাবে `questions` টেবিলে যুক্ত হয়ে যায়।
- **Reject:** ত্রুটিপূর্ণ প্রশ্ন বাতিল করা যায়।

## ৪. AI Extraction Format (Text, OCR & Photo Parsing)

অ্যাডমিন প্যানেলের **AI Question Extractor** বা `/api/admin/extract` রুট দিয়ে প্রশ্নপত্রের পিডিএফ টেক্সট, স্ক্যানড ছবি বা প্রশ্নব্যাংকের কপি পেস্ট করলে এআই নিচে উল্লেখিত সুনির্দিষ্ট JSON ফরম্যাটে আউটপুট প্রদান করে:

```json
{
  "questions": [
    {
      "subject": "physics_1",
      "paper": 1,
      "chapterId": "phy1_ch2",
      "topic": "ভেক্টর যোগ ও বিয়োগ",
      "questionText": "দুটি সমান ভেক্টরের লব্ধি তাদের যেকোনো একটির মানের সমান হলে ভেক্টরদ্বয়ের মধ্যবর্তী কোণ কত?",
      "math_formula_latex": "R = \\sqrt{P^2 + Q^2 + 2PQ\\cos\\alpha}",
      "options": [
        { "id": "A", "text": "$60^\\circ$" },
        { "id": "B", "text": "$90^\\circ$" },
        { "id": "C", "text": "$120^\\circ$" },
        { "id": "D", "text": "$180^\\circ$" }
      ],
      "correctAnswer": "C",
      "explanation": "যেহেতু $P = Q = R$, সুতরাং $P^2 = P^2 + P^2 + 2P^2\\cos\\alpha \\implies \\cos\\alpha = -\\frac{1}{2} \\implies \\alpha = 120^\\circ$।",
      "explanation_latex": "\\cos\\alpha = -0.5 \\implies \\alpha = 120^\\circ",
      "university": "DU",
      "year": "2023-24",
      "difficulty": "medium",
      "tags": ["DU 23-24", "Engineering", "Vector", "Important"]
    }
  ]
}
```

### AI এক্সট্রাকশনের ক্ষেত্রে গুরুত্বপূর্ণ নিয়মাবলি:
1. অপশনগুলোর কি (Key) অবশ্যই `options` অবজেক্ট বা অ্যারে আকারে `A, B, C, D` লেবেল যুক্ত থাকবে।
2. গাণিতিক সূত্র, পাওয়ার, ভগ্নাংশ ও গ্রিক অক্ষরের জন্য স্ট্যান্ডার্ড LaTeX ফরম্যাট (যেমন: `\\frac{a}{b}`, `\\sqrt{x}`, `\\theta`, `\\lambda`) ব্যবহার করা বাধ্যতামূলক।
3. প্রতিটি প্রশ্নের জন্য বিশ্ববিদ্যালয় ও সাল সংবলিত ট্যাগ (যেমন: `"DU 22-23"`, `"BUET 21-22"`, `"GST 23-24"`) যুক্ত করতে হবে।

## ৫. Metadata Configuration & `admissionData.ts` Extension

নতুন বিষয় বা চ্যাপ্টার যোগ করার সময় নিচের ফাইলগুলো আপডেট করা আবশ্যক:

1. **`src/data/admissionData.ts`:**
   - `SUBJECTS_DATA`: নতুন বিষয়ের বাংলা নাম, আইকন এবং কোড যুক্ত করুন।
   - `CHAPTERS_DATA`: অধ্যায়ের আইডি (`subject_chX`), শিরোনাম এবং পেপার সংখ্যা কনফিগার করুন।
   - `UNIVERSITIES_DATA`: নতুন বিশ্ববিদ্যালয়ের ভর্তি পরীক্ষার ধরণ ও মানবন্টন যুক্ত করুন।

2. **Types Consistency (`src/types.ts`):**
   - নিশ্চিত করুন `SubjectId` এবং `ChapterId` টাইপগুলো নতুন আইডির সাথে মিলে।
   - ফ্রন্টএন্ড এবং ব্যাকএন্ড উভয়ের জন্য সুনির্দিষ্ট ফিল্ড নেমিং (`questionText` / `question_text`) স্ট্যান্ডার্ডাইজড রূপান্তরকারী ফাংশনের মাধ্যমে হ্যান্ডেল করা হয়।
